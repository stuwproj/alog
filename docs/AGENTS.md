# alog documentation instructions

Follow the master documentation guidelines in
[stuwproj/docs/AGENTS.md](https://github.com/stuwproj/docs/blob/main/AGENTS.md).
Consult that file when editing these docs; its guidance applies here.

- Lead with practical usage, observable behavior, and guarantees.
- Describe use cases factually and only where the library is applicable.
- Explain implementation details when they clarify correctness or operational trade-offs.
- Verify API names, defaults, and guarantees against current code and tests.
- Keep examples runnable and tested where possible. Preserve existing
  `<!-- EXAMPLE:... -->` synchronization markers.
- Keep the README short and link to these guides instead of duplicating them.
- Link questions and feedback to https://github.com/stuwproj/docs/discussions.
- Open regular pull requests, not drafts.
